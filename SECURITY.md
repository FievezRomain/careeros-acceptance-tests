# Security policy

This public repository contains synthetic acceptance fixtures only.

- Never commit passwords, access tokens, private keys, phone numbers, real resumes, real applications or personal contact data.
- Test accounts and provider destinations must belong to isolated local or dedicated test environments.
- External delivery adapters remain disabled by default; tests use fakes unless a separately approved sandbox exists.
- Do not open a public issue with exploitable details. Use GitHub private vulnerability reporting when available.
